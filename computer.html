LESSON 1: Inserting Media (Image, Video, and Music)

1.1 Tech Input: The Big Idea

HTML5 introduced two very widely used elements for multimedia: the <audio> tag and the <video> tag[cite: 1]. Before HTML5, a web page could only play sound or video if the visitor's browser had an external plug-in installed, such as Adobe Flash[cite: 1]. If the plug-in was missing or outdated, the media simply would not play[cite: 1].

With HTML5, the browser itself understands how to play media[cite: 1]. This means:

  • Media plays seamlessly (smoothly) inside the web page[cite: 1].
  • No external plug-in is required[cite: 1].
  • The code is shorter and easier to write[cite: 1].

One warning from the lesson: the way media works may differ between updated browsers and older browsers, and some media may be affected by copyright restrictions[cite: 1]. Always use media you have permission to use[cite: 1].

Memorize: HTML5 introduced the <audio> and <video> tags so media can play without a plug-in.[cite: 1]

1.2.2 The <img> Element Structure

Images are added using the img element[cite: 1]. An image is a separate file: the HTML page does not contain the picture itself, it only points to it[cite: 1]. That is why we say that inserting an image is implanting a separated image file inside the HTML[cite: 1].

<!DOCTYPE html>
<html>
  <head>
    <title></title>
  </head>
  <body>
    <img src="" width="" height="" alt="">
  </body>
</html>

The four core attributes are:

  • src – the source: which image file to show and where it is located[cite: 1].
  • width – how wide the image is[cite: 1].
  • height – how tall the image is[cite: 1].
  • alt – alternative text describing the image[cite: 1].

1.2.3 Important Rule About <img>

In HTML5 the <img> tag does not need a closing tag or a closing slash (/)[cite: 1]. It is an empty element, meaning it has no content between an opening and closing tag[cite: 1]. You write <img src="dog.jpg"> and that is complete[cite: 1].

1.3 Setting the Image Directory (the src attribute)

<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Image</title>
  </head>
  <body>
    <img src="images/dog.jpg" alt="Jolly Dog" width="500" height="300">
  </body>
</html>

Line-by-line explanation:

  • src="images/dog.jpg" – the browser should open the folder named images and show the file dog.jpg inside it[cite: 1]. The slash (/) separates a folder from the file inside it[cite: 1].
  • alt="Jolly Dog" – alternative text[cite: 1].
  • width="500" height="300" – shown 500 pixels wide and 300 pixels tall[cite: 1].

Three Ways to Write File Location

Situation What you write in src Example
HTML file and image are in the same folder Only the file name[cite: 1] src="dog.jpg"[cite: 1]
Image is inside a subfolder Folder name, slash, file name[cite: 1] src="images/dog.jpg"[cite: 1]
Image is from another website The complete URL address[cite: 1] src="https://example.com/dog.jpg"[cite: 1]

1.4 Width and Height of an Image

<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Image</title>
  </head>
  <body>
    <img src="images/dog.jpg" alt="Jolly Dog" width="50%" height="30%">
  </body>
</html>
  • Writing width="500" means 500 pixels[cite: 1].
  • Writing width="50%" takes up 50 percent of the available space[cite: 1].
  • If undeclared, the browser loads the original image size[cite: 1]. Specifying dimensions lets the browser reserve space during loading so layout does not jump around[cite: 1].

1.5 The alt Attribute

Always include alt text because it assists visitors with visual impairments using screen readers and displays descriptive text if an image fails to load[cite: 1].

1.6 Embedding a Video

<!DOCTYPE html>
<html>
  <body>
    <video width="400" height="250" controls>
      <source src="movie_title.mp4" type="video/mp4">
      <source src="movie_title.ogg" type="video/ogg">
    </video>
  </body>
</html>
  • controls – adds play, pause, volume, progress bar, and full-screen buttons[cite: 1].
  • <source> – states media files; multiple sources let the browser pick the first format it recognizes[cite: 1].
  • type="video/mp4" – specifies the MIME type[cite: 1].

Flash Fallback Method (Obsolete)

<video src="sample_video.ogv" controls>
  <object data="sampleflv.swf" type="application/x-shockwave-flash">
    <param value="sampleflv.swf" name="movie"/>
  </object>
</video>

LESSON 2: iFrames

2.1 Tech Input: What Is an iFrame?

iFrame stands for inline frame, used to display external web content directly inside your page[cite: 1]. An inline frame is always composed of two or more web pages: the main page containing the frame, and second page providing the frame content[cite: 1].

2.2 Creating iFrames

Main Page (Seamless Frame)

<!DOCTYPE html>
<html>
  <head>
    <title>1st_iframe_sample</title>
  </head>
  <body>
    <iframe src="2nd_html_file.html" width="150" height="150" seamless></iframe>
  </body>
</html>

Second Web Page (Framed Content)

<!DOCTYPE html>
<html>
  <head>
    <title>2nd_iframe_sample</title>
  </head>
  <body>
    This is the second web page that will appear inside the first web page that we created.
  </body>
</html>

2.3 Name and Target Attributes

The name attribute identifies the <iframe>[cite: 1]. It is referenced by the target attribute of links (<a>) so clicked pages open inside the frame[cite: 1].

Main Code (main.html)

<!DOCTYPE html>
<html>
  <head>
    <title>Main Page</title>
  </head>
  <body>
    <iframe src="1_page.html" name="name_iframe"></iframe>
    <a href="2_page.html" target="name_iframe">Sample Page</a>
  </body>
</html>

3.9 Event Markers (Interactive Listeners)

<!DOCTYPE html>
<html>
  <body>
    <div id="map" style="width:100%; height:500px"></div>
    <script>
      function myMap() {
        var myCenter = new google.maps.LatLng(14.6515619,121.040647);
        var mapCanvas = document.getElementById("map");
        var mapOptions = {center: myCenter, zoom: 5};
        var map = new google.maps.Map(mapCanvas, mapOptions);
        var marker = new google.maps.Marker({position: myCenter});
        marker.setMap(map);
        google.maps.event.addListener(marker, 'click', function() {
          map.setZoom(10);
          map.setCenter(marker.getPosition());
        });
      }
    </script>

  </body>
</html>
