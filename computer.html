Computer 9 – Unit III: CSS (Cascading Style Sheet) for Web Design

Lesson 1: Syntax and Selectors

1.1 CSS Syntax and Rule-Sets

  • Syntax: The logical arrangement of words, codes, and symbols to form a cohesive statement that ensures the correct CSS rule-set is executed[cite: 11].
  • Rule-Set: A CSS statement composed of two major parts: a selector and a declaration block[cite: 12, 18].
  • Parts of a Rule-Set:
    • Selector: Identifies the HTML element you want to style (e.g., h1)[cite: 12].
    • Declaration Block: Contains one or more declarations enclosed inside a pair of curly brackets { }[cite: 12, 18].
    • Declaration: A single styling instruction consisting of a property and a value separated by a colon (:), and always ending with a semicolon (;)[cite: 12, 18].
    • Property: Identifies which aspect of the element you want to style (e.g., color, background, font, padding)[cite: 12].
    • Value: Identifies the specific style assigned to the property (e.g., blue, white, center)[cite: 12].
/* Anatomy of a CSS Rule-Set */
selector {
    property: value;
    property: value;
}

/* Example */
h1 {
    color: blue;
    background: white;
}

1.2 Four Types of CSS Selectors

Selector Type Symbol / Syntax Purpose & Scope Example
Element Selector[cite: 12] Element name without angle brackets <>[cite: 12, 20] Styles all instances of a specific HTML tag on the page[cite: 12]. h1 { color: darkgreen; text-align: center; }[cite: 12]
ID Selector[cite: 13] Pound/number sign (#) + name (cannot start with a number)[cite: 13] Unique identifier that styles only one single element matching id="name"[cite: 13, 18]. #sample123 { text-align: center; color: cyan; }[cite: 13]
Class Selector[cite: 15] Period (.) + name (cannot start with a number)[cite: 15] Styles multiple elements that share the same class="name" attribute[cite: 15, 18]. .sample123 { text-align: center; color: gray; }[cite: 15]
Group Selector[cite: 16] Selectors separated by a comma (,)[cite: 16] Minimizes code by applying the exact same style rules to multiple elements at once[cite: 16, 18]. h1, h2, p { text-align: center; color: black; }[cite: 16]

Code Examples of Selectors in HTML

<!DOCTYPE html>
<html>
<head>
<style>
    /* ID Selector - applies only to the element with id="uniqueTitle" */
    #uniqueTitle { text-align: center; color: cyan; }

    /* Class Selector - applies to all elements with class="sharedStyle" */
    .sharedStyle { text-align: center; color: gray; }

    /* Group Selector - applies to all h2 and p elements */
    h2, p { font-family: Arial; }
</style>
</head>
<body>
    <h1 id="uniqueTitle">This is a Unique Heading</h1>
    <h2 class="sharedStyle">Subheading with Class</h2>
    <p class="sharedStyle">Paragraph sharing the same class style.</p>
</body>
</html>

1.3 CSS Comments

  • Syntax: Enclosed between an opening comment bar (/*) and a closing comment bar (*/)[cite: 17].
  • Purpose: Acts as side notes, explanations, or bookmarks for developers reading the source code[cite: 17, 18].
  • Browser Behavior: Ignored by the web browser—comments are not executed as code and never appear on the rendered web page[cite: 17, 20]. Can be placed anywhere inside CSS or within <style> blocks[cite: 17].
/* Attention! This is a CSS comment and will not show up in the browser. */

Lesson 2: What is CSS?

2.1 Core Concept & Relationship with HTML

  • Cascading Style Sheet (CSS): A style sheet language used to manage the visual presentation, layout, and design of HTML elements on a web page[cite: 1, 8].
  • HTML vs. CSS Analogy:
    • Building Analogy: HTML is the structure (foundation, walls, floors, roof)[cite: 2]; CSS is the visual design (paint colors, lighting, furniture, fixtures)[cite: 2].
    • Pizza Analogy: HTML is the crust/dough[cite: 2]; CSS is the toppings[cite: 2].

2.2 Three Ways to Insert CSS in HTML

Method Where It Is Placed Best Used For Key Syntax / Requirement
1. External Style Sheet[cite: 2] A separate .css file linked inside the HTML <head> using <link>[cite: 2, 3]. Styling an entire multi-page website from a single centralized file[cite: 2, 6]. Saved with .css extension; must not contain any HTML tags[cite: 3, 7].
2. Internal Style Sheet[cite: 3] Inside the <style> element within the HTML <head> section[cite: 3]. Applying unique styles to a single HTML web page only[cite: 3]. Enclosed within <style> ... </style> tags[cite: 3].
3. Inline Style Sheet[cite: 4] Directly inside a specific HTML opening tag using the style attribute[cite: 4]. Quick, one-off styling for a single specific element (use sparingly)[cite: 4, 7]. <tag style="property: value;">[cite: 4]

Syntax Examples for All Three Methods

<!-- 1. EXTERNAL STYLE SHEET (in index.html) -->
<head>
    <link rel="stylesheet" type="text/css" href="samplestylesheet.css">
</head>
<!-- Inside samplestylesheet.css (No HTML tags allowed!):
body { background-color: black; }
h1 { color: white; margin-left: 30px; }
-->

<!-- 2. INTERNAL STYLE SHEET -->
<head>
    <style>
        body { background-color: lightyellow; }
        h1 { color: darkgreen; margin-left: 20px; }
    </style>
</head>

<!-- 3. INLINE STYLE SHEET -->
<h2 style="color: black; background-color: yellow; margin-left: 20px;">Sample Heading</h2>

2.3 Advantages of Using CSS

  1. Worry-free Coding: Automatically resolves redundant styles by applying the last defined rule, eliminating manual proofreading for conflicting styles[cite: 6].
  2. Efficient: Saves time from tedious line-by-line editing, making large websites much easier to build and maintain[cite: 6].
  3. Consistent Design: Keeps design uniform, clean, and elegant across pages so visitors focus on content[cite: 6].
  4. Faster Loading: Centralizing styles in one .css file reduces repeated inline code, helping web pages load faster[cite: 6].
  5. Browser Compatibility: Optimizes website layouts so content renders properly across major web browsers[cite: 6].

2.4 CSS Order of Priority (Cascading Rules)

When multiple styles target the same HTML element and overlap, CSS follows a strict priority hierarchy from highest to lowest[cite: 6, 9]:

  1. Inline Style Sheet (Highest Priority): Always overrides both internal and external styles[cite: 6, 9].
  2. Internal and External Style Sheets: Evaluated in the order they appear in the HTML document—whichever comes last wins[cite: 4, 5, 6]. (If <style> is placed after <link>, internal overrides external; if <link> is placed after <style>, external overrides internal)[cite: 5].
  3. Browser Default Style (Lowest Priority): Applied automatically when no CSS rules are defined[cite: 6, 9].
Important Coding Reminders:
1. Never put a space between a number and its unit (write margin-left: 30px;, not 30 px;), or the browser will ignore the property[cite: 7].
2. Avoid excessive inline styles—overusing them defeats the efficiency and maintainability of CSS[cite: 7].
